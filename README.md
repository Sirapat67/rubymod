# Ruby Mod (NeoForge 1.21.1)

Adds: Ruby (item), Block of Ruby, Ruby Sword, a creative tab, and recipes.

## Build & run
1. Install JDK 21 and Gradle 8.8+ (or copy the gradle wrapper files from the official NeoForge MDK).
2. In this folder run `gradle wrapper` once, then:
   - ./gradlew runClient  - launch Minecraft with the mod
   - ./gradlew build      - jar appears in build/libs/
3. In-game: Creative mode > "Ruby Mod" tab, or /give @s rubymod:ruby 64

Edit versions in build.gradle if you target a different NeoForge/Minecraft version.
